# 阶段 1 分析报告 - lambda-refarch-streamprocessing

## 基本信息
- **上游仓库**: aws-samples/lambda-refarch-streamprocessing
- **语言**: JavaScript (Lambda) + Python (Producer)
- **IaC**: AWS SAM (template.yaml)
- **体量**: ~0M (极小)

## AWS 服务依赖
| 服务 | 用途 | 映射 |
|------|------|------|
| Kinesis Stream | 数据流接入 | DIS (数据接入服务) |
| Lambda (Node.js 6.10) | 事件处理器 | FunctionGraph |
| DynamoDB | 事件数据存储 | GeminiDB (DynamoDB 兼容) |
| IAM Role | Lambda 执行角色 | IAM 委托 |
| IAM User + AccessKey | Producer 推送凭证 | IAM 委托 + AK/SK |
| S3 | Lambda 代码存储 | OBS |

## 架构流程
1. Producer (twitter2kinesis.py) → 推送数据到 Kinesis Stream
2. Kinesis Stream → 触发 Lambda (ddb_eventprocessor.js)
3. Lambda → 解析数据，写入 DynamoDB 表

## 注意事项
- Twitter Streaming API 已于 2018 年废弃，Producer 需改用模拟数据源
- Lambda Runtime Node.js 6.10 已 EOL，需升级到 Node.js 18+
- SAM → Terraform 重写
